Course · logs, metrics and traces

Cost-efficient observability, proven

A course on a logs, metrics and traces platform built from OpenTelemetry, OpenData Buffer, ClickHouse and HyperDX: the problem it addresses, how it works, how it was tested, and what the evidence does and does not show.

How to use this course

Start with the Story track, which takes about 20 minutes and is written for everyone. Then continue into the track that matches your work. Each module opens with what you will be able to do, explains one idea with a figure or an interactive you can change, shows real evidence captured from this stack, and ends with a short quiz. The quiz explains every wrong answer, so use it to check your reasoning.

What is real, and what is not

The test results, logs, database rows and screenshots in this course were captured from the platform running on one laptop, and each carries its source and capture time in evidence/manifest.json. The cost figures are a model: they use AWS list prices and a stated set of assumptions, and no part of the platform has run on AWS.

Read the limits. The platform has not been load-tested at production volume, it has not run against real AWS S3, and the cost comparison depends on engineer time that is assumed. Module 11 lists the open limits found so far.
